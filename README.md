# SiteVerge

Architectural development intelligence: find buildable sites in any U.S. city, test what fits, and understand the economics.

**Live site:** https://frosty7352-gif.github.io/SiteVerge/

SiteVerge searches a city's stronger neighborhoods for vacant parcels, screens out lots that can't be built on, ranks the rest with weighted criteria, and runs a preliminary feasibility analysis on each site: 3D massing, a monthly pro forma with a 1,000-run Monte Carlo simulation, and neighborhood and environmental context. Results export as a PDF feasibility report, a site plan sheet, DXF/OBJ/GeoJSON files and an Excel pro forma.

All data comes live from public sources (county parcel layers, city zoning GIS, FEMA, USDA, USGS, the U.S. Census and others). Sources are listed in the app under About → Data & credits.

Results are a preliminary screen, not a zoning determination, survey, appraisal or design. Confirm zoning, title and utilities with the local authority and licensed professionals before acting on any site.
